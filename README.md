# NewsBot 2.0

AI-powered news analysis platform built with Python, NLP pipelines, and Streamlit.

## Features

- Live RSS news ingestion
- NLP preprocessing
- Sentiment analysis
- Topic classification
- Batch article processing
- CSV dataset generation
- Streamlit dashboard support

## Tech Stack

- Python
- spaCy
- pandas
- TextBlob
- Streamlit
- feedparser

## Current Status

MVP in active development.
